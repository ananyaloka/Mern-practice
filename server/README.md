# Student Management System

## Project Overview
This project is a Student Management System built using the MERN stack.

## Technologies Used
- MongoDB
- Express.js
- React.js
- Node.js
- Vite

## Project Structure
- client: React frontend application
- server: Express backend application

## Setup Instructions

### Frontend
1. Open a terminal.
2. Navigate to the client folder:
   `cd client`
3. Install dependencies:
   `npm install`
4. Start the frontend:
   `npm run dev`

Frontend URL: http://localhost:5173

### Backend
1. Open a second terminal.
2. Navigate to the server folder:
   `cd server`
3. Install dependencies:
   `npm install`
4. Start the backend:
   `node server.js`

Backend URL: http://localhost:5000
